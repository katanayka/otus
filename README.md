# OTUS Python Homeworks

This repository contains multiple homework assignments for the OTUS Python course.
Each task lives in its own folder and has its own instructions.

## Contents
- `01` — Log analyzer
- `02` — Type annotation trainer tasks
- `03` — Scoring API
- `04` — Scoring API tests + store
- `05` — Warehouse management (DDD)
- `06` — HTTP server
- `07` — Django tutorial (polls)
- `08` — FastAPI ML model serving
- `09` — FastAPI ML model serving with JWT auth
- `10` - Logistic regression (SGD, Amazon reviews)
- `11` - OTUS-GPT (fine-tuned GPT bot)
- `12` - Memcache loader (concurrent)

## How to run
See the README inside each folder (for example, `01/README.md` or `06/homework/README.md`).
